# 作品集项目设计规范文档
> 项目深色主题UI规范，对应 style.css 中 CSS 变量，包含配色、字体、间距、组件规则。

## 1. 配色规范
| 分类 | CSS变量 | 色值 | 使用场景 |
|---|---|---|---|
| 主色 | `--primary` | `#e85d78` | 按钮、标记圆点、序号圆点、强调高亮 |
| 主色柔和 | `--primary-soft` | `#f07b91` | hover、交互悬浮状态 |
| 主色深色 | `--primary-dark` | `#d14d67` | 按下状态 |
| 页面背景 | `--bg` | `#0b1210` | 页面全局背景，搭配径向渐变 |
| 卡片背景 | `--card` | `#141c1a` | 卡片、详情面板容器底色 |
| 卡片悬浮 | `--card-hover` | `#1a2421` | 卡片鼠标hover背景色 |
| 主要文字 | `--text` | `#ffffff` | 标题、正文主要文字 |
| 次要文字 | `--text-muted` | `#8d9692` | 描述文本、辅助说明文字 |
| 边框 | `--border` | `rgba(255, 255, 255, 0.05)` | 卡片分割边框，弱透明边框 |

> 整体为**深色暗色主题**，低亮度背景，粉色作为唯一强调色，边框使用极低透明度白色，不使用厚重阴影。

## 2. 字体规范
### 字体族
- 优先字体：`"Plus Jakarta Sans"`
- 降级中文字体：`"PingFang SC"`, `"Microsoft YaHei"`, sans‑serif

### 字号、字重、行高
| 元素 | 字号 | 字重 | 行高 | 字间距 |
|---|---|---|---|---|
| 大标题 hero h1 | `clamp(2.35rem,5vw,3.15rem)` | 800 | 1.18 | `-0.03em` |
| 板块标题 section‑title | `1.85rem` | 800 | 默认 | `-0.03em` |
| 卡片标题 meal‑title | `1.02rem` | 700 | 默认 | `-0.02em` |
| 正文描述 hero‑sub | `0.92rem` | 400 | 1.75 | 无 |
| 卡片描述 meal‑desc | `0.82rem` | 400 | 1.6 | 无 |
| 全局body | 基准 | 400 | 1.65 | 无 |

> 标题使用粗重字重，负字间距收紧；说明文字字重降低，行高放大保证阅读舒适度。

## 3. 间距规范
### 页面布局
- 页面容器 `.page`：最大宽度 `1080px`，左右边距 `48px`，上下内边距 `96px 0 80px`
- 板块 `.works`：上间距 `88px`
- 卡片网格 gap：`20px`

### 组件内边距
- 卡片信息区 `.meal‑info`：`18px 18px 22px`
- 详情面板 `#meal‑details`：`1.5rem`

### 模块垂直间距
- hero标题下方：`22px`
- hero圆点底部外边距：`28px`
- section‑title底部外边距：`36px`

> 移动端适配：页面上下padding改为`64px`，works上间距改为`56px`；卡片网格由3列变为单列，最大宽度`420px`居中。

## 4. 组件样式规范
### 4.1 卡片组件 `.meal`
- 背景：`var(--card)`
- 边框：`1px solid var(--border)`
- 圆角：`var(--radius-card)` → **22px**
- 溢出：`overflow:hidden`
- 过渡：`0.25s ease`
- hover行为：背景变为`var(--card-hover)`，向上位移`translateY(-4px)`
- 卡片图片容器高度固定：`168px`，图片 `object‑fit:cover`

### 4.2 按钮 Button
1. **主按钮**
    - 背景：`var(--primary)`
    - 文字颜色：白色
    - 圆角：`var(--radius-btn)` → **999px（胶囊圆角）**
    - 内边距：`10px 20px`
2. **返回按钮 #back‑btn（描边按钮）**
    - 背景：透明
    - 文字颜色：`var(--primary)`
    - 边框：`1px solid var(--primary)`
    - 内边距：`8px 16px`
    - 圆角：胶囊圆角

### 4.3 交互与动效
- 全局过渡时长：`--transition:0.25s ease`
- html开启平滑滚动：`scroll‑behavior:smooth`
- 卡片点击：JS监听click，读取`data‑url`属性新开标签页跳转。

### 4.4 隐藏状态
- `.hidden` 类：`display:none`，用于条件隐藏模块。

## 5. 响应式规则
- 断点：`@media(max‑width:900px)`
- 卡片网格：三列 → 单列，卡片容器最大宽度`420px`居中；页面、板块垂直间距缩小，保证移动端留白舒适。

## 6. 设计原则
1. 深色极简风格，少阴影，依靠**背景色差+细微边框**区分层级。
2. 强调色仅使用粉色`#e85d78`，不引入多种彩色。
3. 卡片hover使用位移+背景色变化，提供柔和反馈。
4. 全部样式复用CSS变量，修改主题只需要修改`:root`内色值。
